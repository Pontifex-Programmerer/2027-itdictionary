Stylesheet

A file that is an addition to a main file that has instructions/rules that set the style and design in the main file. It controls all the design and aesthetics in the project but also layout. In web design they call it CSS(cascading stylesheets) which can be recognized with the tag: “.css”. The word styles sheet can also be used outside the IT context and just be a normal document.

(Cambridge dictionary, u.å.)
